# Sistema de Comedor Universitario UNAMBA

## Descripción
Sistema académico para gestionar el comedor universitario de la Universidad Nacional Micaela Bastidas de Apurímac (UNAMBA). Su desarrollo se organiza en versiones incrementales para practicar el control de versiones y el trabajo colaborativo.

## Objetivo
Desarrollar progresivamente un sistema de gestión del comedor universitario y aplicar un flujo de trabajo con Git, GitHub y resolución de conflictos mediante P4Merge.

## Tecnologías
- **Git:** control de versiones local, ramas y fusiones.
- **GitHub:** alojamiento del repositorio y colaboración remota.
- **P4Merge:** comparación de archivos y resolución visual de conflictos.
- **Python:** configuración y módulos del sistema.

## Colaboradores simulados
| Colaborador | Participación simulada |
| --- | --- |
| master | Integración y mantenimiento de la versión principal. |

## Estado de la v1.0
La versión inicial contiene la documentación y los parámetros generales. Los módulos de versiones posteriores aún no se crean.

El documento requisitos.md reserva los códigos RF01 a RF13 y RNF01 a RNF09. Su contenido está pendiente de cotejo con el PDF del caso práctico, que no está disponible en el espacio de trabajo.

La configuración inicial debe conservarse para el ejercicio posterior de conflictos de Git y su resolución con P4Merge.
